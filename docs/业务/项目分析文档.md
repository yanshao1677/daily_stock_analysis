# 📈 股票智能分析系统 - 项目架构分析

## 一、项目概览

这是一个基于 AI 大模型的 **A 股/港股/美股自选股智能分析系统**，核心功能是：
- 每日自动获取股票数据
- 通过 LLM（大语言模型）进行智能分析
- 生成「决策仪表盘」报告
- 推送到企业微信/飞书/Telegram/Discord 等多渠道

## 三、业务场景功能划分

### 1. 个股分析流程（核心）

**入口文件**: `main.py` → `src/core/pipeline.py`

**流程步骤**:

```
Step 1: 数据获取
├── fetcher_manager.get_daily_data()     # 历史K线数据
├── fetcher_manager.get_realtime_quote() # 实时行情(量比/换手率)
├── fetcher_manager.get_chip_distribution() # 筹码分布
└── fetcher_manager.get_fundamental_context() # 基本面聚合

Step 2: 技术分析
└── trend_analyzer.analyze() → 计算 MA5/MA10/MA20、乖离率、量能状态

Step 3: 情报搜索
└── search_service.search_comprehensive_intel() → 多维度新闻搜索

Step 4: AI 分析
├── 传统模式: analyzer.analyze(context, news_context)
└── Agent模式: _analyze_with_agent() → 多技能策略分析

Step 5: 结果输出
├── 保存到数据库 (SQLite)
├── 生成决策仪表盘报告
└── 推送到配置的通知渠道
```

### 2. 大盘复盘功能

**入口**: `src/core/market_review.py`

**功能**:
- 获取主要指数行情（上证/深证/创业板/道琼斯/纳指/标普）
- 板块涨跌榜
- 市场涨跌统计
- AI 生成市场综述

### 3. Agent 策略问股（多轮对话）

**入口**: `src/agent/`

**架构**:
```
AgentExecutor
├── ToolRegistry (工具注册)
│   ├── 数据工具: get_daily_history, get_realtime_quote
│   ├── 分析工具: analyze_trend
│   ├── 搜索工具: search_stock_news
│   └── 市场工具: get_market_overview
├── SkillManager (策略技能管理)
│   └── 加载 strategies/*.yaml 策略文件
└── LLMToolAdapter (LLM调用适配)
```

**入口**: `api/app.py` (FastAPI)

## 评分标准

### 强烈买入（80-100分）：
- ✅ 多个激活技能同时支持积极结论
- ✅ 上行空间、触发条件与风险回报清晰
- ✅ 关键风险已排查，仓位与止损计划明确

### 买入（60-79分）：
- ✅ 主信号偏积极，但仍有少量待确认项
- ✅ 允许存在可控风险或次优入场点

### 观望（40-59分）：
- ⚠️ 信号分歧较大，或缺乏足够确认
- ⚠️ 风险与机会大致均衡

### 卖出/减仓（0-39分）：
- ❌ 主要结论转弱，风险明显高于收益
```

### 5.2 默认交易技能基线

位置: `src/agent/skills/defaults.py:26-59`

```text
## 默认技能基线（必须严格遵守）

### 1. 严进策略（不追高）
- **绝对不追高**：当股价偏离 MA5 超过 5% 时，坚决不买入
- 乖离率 < 2%：最佳买点区间
- 乖离率 2-5%：可小仓介入
- 乖离率 > 5%：严禁追高！直接判定为"观望"

### 2. 趋势交易（顺势而为）
- **多头排列必须条件**：MA5 > MA10 > MA20
- 只做多头排列的股票，空头排列坚决不碰
- 均线发散上行优于均线粘合

### 3. 效率优先（筹码结构）
- 关注筹码集中度：90%集中度 < 15% 表示筹码集中
- 获利比例分析：70-90% 获利盘时需警惕获利回吐
- 平均成本与现价关系：现价高于平均成本 5-15% 为健康

### 4. 买点偏好（回踩支撑）
- **最佳买点**：缩量回踩 MA5 获得支撑
- **次优买点**：回踩 MA10 获得支撑
- **观望情况**：跌破 MA20 时观望

### 5. 风险排查重点
- 减持公告、业绩预亏、监管处罚、行业政策利空、大额解禁

### 6. 估值关注（PE/PB）
- PE 明显偏高时需在风险点中说明

### 7. 强势趋势股放宽
- 强势趋势股可适当放宽乖离率要求，轻仓追踪但需设止损
```

### 5.3 策略技能 YAML 文件示例

#### 多头趋势策略 - `strategies/bull_trend.yaml`

```yaml
name: bull_trend
display_name: 默认多头趋势
description: 默认个股分析优先策略，识别多头排列、趋势延续与回踩低吸机会。
category: trend
required_tools:
  - get_daily_history
  - analyze_trend

instructions: |
  **默认多头趋势**

  分析框架：

  1. **趋势确认（优先级最高）**
     - 使用 `analyze_trend` 判断 MA5/MA10/MA20 排列。
     - MA5 >= MA10 >= MA20 且 MA20 斜率向上，视为多头结构。

  2. **位置与节奏**
     - 优先"回踩不破"而非"高位追涨"。
     - 当价格距离 MA5/MA10 过远时，提示等待回踩。

  3. **量价验证**
     - 使用 `get_daily_history` 检查突破日/反弹日是否放量。
     - 缩量上涨需谨慎，放量滞涨需警惕分歧。

  4. **交易建议输出**
     - 输出明确的"买入/观望/减仓"倾向及触发条件。
     - 必须给出止损参考（如 MA20 下方或结构低点）。

  评分调整建议：
  - 多头排列 + 趋势强度良好：`sentiment_score +12`
  - 回踩关键均线后企稳：`sentiment_score +8`
  - 跌破 MA20 或趋势转弱：`sentiment_score -12`
```

#### 缠论策略 - `strategies/chan_theory.yaml`

```yaml
name: chan_theory
display_name: 缠论
description: 基于缠论笔、线段、中枢结构，判断趋势级别、买卖点与背驰信号。

instructions: |
  **缠论**

  核心框架：分型 → 笔 → 线段 → 中枢 → 趋势

  ### 1. 判断价格结构（中枢识别）
  - 使用 `get_daily_history` 获取近 60 日日线数据。
  - 识别近期价格的高低点序列，判断当前是否在震荡中枢还是趋势段。

  ### 2. 背驰判断（最高优先级信号）
  - **顶背驰**：价格创新高但MACD红柱面积缩小 → 卖出/减仓信号。
  - **底背驰**：价格创新低但MACD绿柱面积缩小 → 买入/加仓信号。

  ### 3. 买卖点判定
  - **一买**（最强）：下跌趋势中，最后一个中枢出现底背驰。
  - **二买**：离开下跌中枢后的第一次回调不破中枢高点。
  - **三买**：中枢震荡后向上突破（不回中枢内）。
```

### 9.2 添加新的数据源

1. 在 `data_provider/` 下创建新的 fetcher 文件
2. 继承 `BaseDataFetcher` 基类

## 十、总结

项目核心是 **「数据获取 → 技术分析 → AI 分析 → 报告推送」** 的流水线架构。

**提示词设计要点**：
- 围绕 **「决策仪表盘」** 格式
- 强调：一句话结论、精确狙击点位、检查清单可视化
- 内置交易纪律：严进策略、趋势交易、效率优先

**架构特点**：
- 模块化设计，易于扩展
- 支持 GitHub Actions 零成本运行
- 多数据源、多 LLM、多通知渠道
